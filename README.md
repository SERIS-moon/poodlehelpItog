# PoodleHelp: сайт-анкета для приюта

Всё в одном репозитории: сайт (`index.html`, `config.js`) и сервер для общих заявок (`server.js`).
Пароль в файлах не хранится, поэтому репозиторий может быть публичным.

## 1. Сайт на GitHub Pages
1. Создайте репозиторий на github.com и загрузите в него все файлы из этой папки (сами файлы, не папку).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Без шага 2 сайт работает в режиме «без сервера»: заявки видны только в браузере того, кто их заполнил.

## 2. Сервер на Render (чтобы приют видел все заявки)
1. На render.com: New → Web Service → подключите этот же репозиторий.
   Build Command: `npm install`, Start Command: `npm start`.
2. В разделе Environment добавьте:
   - `STAFF_PASSWORD`: пароль для входа сотрудников приюта
   - `ALLOWED_ORIGIN`: `https://ВАШ-ЛОГИН.github.io` (адрес сайта на Pages, без слэша на конце)
3. После деплоя Render покажет адрес вида `https://poodlehelp-api.onrender.com`.
   Откройте его: должна быть надпись «PoodleHelp API работает».
4. Откройте в репозитории файл `config.js` и впишите этот адрес:
   `window.POODLE_API_URL = "https://poodlehelp-api.onrender.com";`

Чтобы сменить пароль, измените `STAFF_PASSWORD` на Render и перезапустите сервер.

## Важно
- Заявки хранятся в файле `data.json` на сервере. На бесплатном тарифе Render он стирается при перезапуске.
  Для постоянного хранения нужен платный диск или VPS.
- Бесплатный сервер «засыпает»: первый вход после паузы может занять около минуты.
- Файлы с точкой в начале (`.nojekyll`, `.gitignore`, `.env.example`) на Mac скрыты: Cmd + Shift + точка.

## Безопасность
- Заявки, фото и управление собаками доступны только после ввода пароля; сессия 8 часов.
- Не больше 8 попыток входа за 10 минут с одного адреса.
- Фото лица (уменьшенные) хранятся на сервере и видны только сотрудникам приюта; заявителю об этом сказано.
- Статус заявки по телефону виден любому, кто знает номер (только собака, статус и причина).
